Token Management
Access Token (JWT)
RS256-signed, 15min TTL. Stored in maf_access httpOnly cookie. Payload: sub, email, role.
Refresh Token
Random 32-byte hex, 7-day TTL. Stored in maf_refresh cookie (path: /auth/refresh). Backed by Redis.
Token Rotation
Old refresh token deleted on use. 60-second grace period for concurrent requests. Single-use grace token.
every API request

Infrastructure
PostgreSQL
User table with wpUserId, googleId, email, role. Prisma ORM.
Redis
Refresh token store. Keys: refresh:{token} → userId. Grace keys for rotation race conditions.
Cookie Security
httpOnly, secure (prod), sameSite: lax, domain: .maf.run. No client-side token access.

Key Files

Backend (api/src/auth/)

  • auth.controller.ts — login, refresh, logout, Google callback endpoints
  • auth.service.ts — WP validation, Google login, token generation
  • jwt.strategy.ts — cookie-based JWT extraction + RS256 verify
  • google.strategy.ts — Passport Google OAuth2 strategy
  • roles.guard.ts — RBAC guard via Reflector metadata
  • auth.types.ts — WpUserInfo, TokenPayload, OAuthState interfaces

Frontend (src/)

  • services/api-client.ts — fetch wrapper with auto-refresh mutex
  • services/auth-service.ts — login(), getMe(), logout() API calls
  • contexts/auth-context.tsx — React auth state provider
  • pages/login-page.tsx — WP + Google login UI
  • components/layout/protected-route.tsx — auth guard
  • components/layout/admin-protected-route.tsx — ADMIN role guard
